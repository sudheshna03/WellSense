# Methodology
Target fixed before training (self-reported depression). Features grouped in tiers A (demographic/academic), B (+anxiety, panic), C (+treatment, sensitivity only). Preprocessing lives inside sklearn Pipelines, so every transform is fitted on training folds only. Evaluation: 5x5 repeated stratified CV (25 outer folds, identical for all models); models with grids are tuned in an inner 3-fold CV on the training fold (nested). Metrics: accuracy, balanced accuracy, F1, ROC-AUC (mean and SD over folds). A separate untouched test set was not used because 101 rows (about 7 test positives) would make it unreliable; nested CV is the unbiased estimate. A first tuned-MLP run used sklearn's built-in early stopping on ~6 validation rows and under-trained (below chance); it was replaced by an inner-CV-selected iteration budget and everything was rerun.
